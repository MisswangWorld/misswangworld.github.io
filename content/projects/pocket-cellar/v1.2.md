# Changelog

## [1.2.0] – 2026-03-18

### Added
- **Duplicate bottle**: In wine detail view mode, a "Duplicate" button navigates to the position picker so the same wine can be placed in another slot (uses existing `copy` flow).
- **Archive deduplication**: When the archive contains wines with the same name + winery + vintage, a "Merge (N)" button appears in the archive header. Tapping opens a sheet listing all duplicate groups; confirming keeps the most complete record in each group and removes the rest.
- **Off-shelf wines**: New "散存库 / Off-Shelf" section (accessible from the hamburger menu) tracks wines owned but not stored in a cellar grid. Each entry has a quantity with inline +/− controls. When quantity reaches zero, the wine is moved to the archive with duplicate detection.
- **Redesigned quick view**: Wine preview modal rebuilt — full-width image/colour block at the top, year and type badges, structured detail rows for grape varieties, region/country, and price (market value preferred over purchase price).
- **Move bottle**: Long-pressing a bottle in the cellar grid now shows a "Move" option. Tapping it opens the position picker where you can select any empty slot — in the same cellar or a different one. The source bottle is highlighted so you always know what you're moving.
- **Photo fullscreen viewer**: Tapping any photo in wine detail opens a fullscreen lightbox. Swipe through multiple photos with a page counter, tap anywhere or press ✕ to close.
- **Delete photos in edit mode**: When editing a wine, each photo thumbnail shows a ✕ badge in the top-right corner. Tapping it removes that photo immediately.
- **Country → region filtering**: Region picker now shows only the regions that belong to the selected country. Changing country clears the region field. Custom regions are stored with their associated country and filtered accordingly. **Migration**: custom regions added in earlier versions carry no country tag (`country: ''`) and remain visible under every country until the user explicitly selects one — at that point the region is automatically bound to the selected country and stops appearing elsewhere.
- **Winery autocomplete**: Winery field shows inline suggestions drawn from all existing wines (cellar + off-shelf + archive) while typing.
- **Recent items first**: Country, region, and grape variety pickers surface the 5 most recently used values at the top of the list.
- **Search in pickers**: Country, region, and grape variety modals now have a live search bar at the top to filter options as you type.
- **Custom options management**: New "Custom Options" section in Settings lists all custom countries, regions, and grape varieties with inline rename (tap ✎) and delete (tap ✕) controls. Deduplication is enforced on rename.
- **KeyboardAvoidingView**: Wine detail and off-shelf detail screens now scroll correctly when the keyboard is open, keeping bottom fields accessible.
- **Photo persistence**: Photos are now stored as base64 data URIs instead of temporary `file://` paths, so they survive app updates and reinstalls. On first launch after upgrading, a one-time migration attempts to convert any existing `file://` photos to base64; photos that are still accessible will be preserved, while those already cleared by iOS (typically camera shots stored in `tmp/`) will be removed gracefully and replaced with the wine's colour block.
