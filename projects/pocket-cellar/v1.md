> Your cellar, in your pocket. · 你的酒，尽在掌握。

Pocket Cellar is a personal wine collection manager for iPhone. It was built for home collectors who want a beautiful, spatial way to manage their cellar — not another spreadsheet disguised as an app.

## The Idea

Most wine tracking apps give you a list. Pocket Cellar gives you a cellar.

The interface mirrors how a real wine rack actually works: a grid, where each cell is a physical bottle slot. You see your collection the way it exists — by position. The colour of each cell tells you the wine type at a glance. The vintage year is printed right on the cell. You don't need to read a list to know what's in your rack.

## Features

### Cellar Grid
- Visual grid layout that maps to your physical cellar
- Colour-coded by wine type (red, white, rosé, sparkling, sweet, fortified, sake)
- Vintage year displayed on each cell
- Multiple cellars with custom row and column counts
- Pre-built templates: mini rack (2×6) through professional cellar (8×10)
- Column and row index labels for easy position reference
- Horizontal and vertical scrolling for large cellars

### Wine Tracking
- Record everything: name, winery, vintage, region, country, grape varieties, type, capacity, purchase price, current value, purchase date, purchase channel, professional score, and notes
- Attach up to 5 photos per bottle (camera or photo library)
- Only the wine name is required — fill in as much or as little as you like

### Archive System
- Move finished or sold bottles to the archive rather than deleting them
- Full wine details are preserved in the archive
- Restore any archived wine back to a cellar — choose the exact position

### List View
- Browse your entire collection as a list
- Filter by wine type, region, country, grape variety, or vintage
- Search by wine name or winery
- Tap any wine in the list to jump directly to its position in the grid (highlighted)

### Settings
- Language: English and Chinese (Simplified), switchable in-app
- Appearance: light, dark, or follow system
- 8 theme colour options (Burgundy Red, Rose, Ruby, Merlot Purple, Champagne Gold, Oak Brown, Navy, Classic Black)
- Currency: AUD, CNY, EUR, GBP, JPY, USD

### Privacy
- Fully offline — all data stored locally on device
- No account required
- No analytics or tracking

## Design Highlights

**Spatial metaphor over lists.** The grid is the product's core bet. It takes slightly more screen space than a list but pays off every time you open the app — you instantly know where things are, what's running low, and what type of collection you have.

**Colour as data.** Wine type is communicated through cell colour, not text. Red wine cells are burgundy, sparkling cells are champagne gold, sake cells are pale blue. You read the cellar visually, not by scanning labels.

**Minimal required input.** The only mandatory field is the wine name. Everything else is optional. This removes the friction that causes people to abandon tracking apps — you can log a bottle in five seconds if you want to.

**Archive, not delete.** Finished bottles are archived, not erased. This preserves a record of what you've drunk, when you bought it, what you paid — a history that becomes more valuable over time.

**Offline-first.** No server, no account, no subscription. Your wine collection is private data. It lives on your device.

## Tech Stack

| Layer | Choice | Why |
|---|---|---|
| Framework | React Native 0.84 (bare) | Native performance, full iOS access |
| Language | TypeScript (strict) | Type safety across the entire codebase |
| State | Zustand 5 | Minimal boilerplate, fast selectors, no context hell |
| Persistence | react-native-mmkv | Synchronous reads, significantly faster than AsyncStorage |
| Navigation | React Navigation 7 | Native stack + bottom tabs, well-maintained |
| i18n | i18next + react-i18next | Proven solution, lazy loading, namespace support |
| Image picker | react-native-image-picker | Camera + library access, actively maintained |
| Date picker | @react-native-community/datetimepicker | Native iOS date picker |

The app uses React Native's **New Architecture** (`RCTNewArchEnabled = true`) for improved performance via JSI (JavaScript Interface), which removes the async bridge bottleneck for synchronous operations.

Components are built with `React.memo`, `useMemo`, and `useCallback` throughout. The cellar grid — potentially rendering hundreds of cells — is optimised so only cells that change re-render.

## Why It's Different

| | Pocket Cellar | CellarTracker | Vivino | VinoCell |
|---|---|---|---|---|
| Visual grid interface | ✓ | — | — | ✓ |
| Offline / no account | ✓ | — | — | — |
| Free, no subscription | ✓ | Freemium | Freemium | Paid |
| Chinese language | ✓ | — | Partial | — |
| Custom cellar layouts | ✓ | — | — | Partial |
| Archive system | ✓ | ✓ | — | — |
| Barcode / label scan | Planned | ✓ | ✓ | — |

CellarTracker is the most comprehensive wine database in the world but requires an account and a browser. Vivino is a social discovery platform first, collection manager second. Pocket Cellar is focused purely on the personal cellar management experience — lightweight, private, and built for the physical rack.

## Future Versions

### V1.x (Near-term)
- **Search in grid view** — find a bottle and highlight its position
- **Drag to rearrange** — drag a bottle from one slot to another

- **Manual backup** — export to JSON and restore from file

- **Drinking window** — peak maturity estimates and alerts
- **Tasting notes** — structured tasting journal per bottle
- **Collection analytics** — value over time, type distribution, region breakdown
- **Decanting and pairing suggestions**
- **Alternative rack layouts** — diamond grid, shelf-style
